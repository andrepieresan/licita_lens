# Security Policy

## Supported versions

LicitaLens is in early-stage development. Security fixes are applied to the latest revision of the `main` branch.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, personal data, or exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature on this repository. Include the affected component, reproduction steps, impact, and any suggested mitigation. Please allow a reasonable period for investigation and remediation before public disclosure.

## Operational responsibility

Operators are responsible for configuring authentication, secrets, network isolation, backups, rate limits, provider credentials, and data-retention rules before exposing an installation publicly. The demo configuration is not a production security profile.
